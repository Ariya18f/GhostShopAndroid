ساخت APK پروژه Ghost Shop

این محیط (Grok) ابزار کامل Android SDK و Gradle برای ساخت APK ندارد.
برای همین یک گردش‌کار GitHub Actions آماده شده تا خودت خیلی راحت APK بگیری:

مراحل (خیلی ساده):
1. برو به github.com و یک مخزن (Repository) جدید بساز (مثلاً اسمش رو بگذار GhostShopAndroid).
2. فایل ZIP این پروژه رو آپلود کن یا محتویات پوشه GhostShopAndroid رو داخل مخزن بریز (شاخه اصلی باید main باشه).
3. برو به تب Actions.
4. گردش‌کار «Build Ghost Shop APK» رو انتخاب کن و دکمه «Run workflow» رو بزن.
5. چند دقیقه صبر کن تا سبز بشه.
6. از بخش Artifacts فایل Ghost-Shop-APK رو دانلود کن.
7. ZIP رو باز کن و فایل app-debug.apk رو روی گوشی کپی کن و نصب کن.

نکته‌ها:
- این APK نسخه دیباگ (آزمایشی) است و برای تست خوبه.
- فروشگاه فعلاً فقط نمونه است؛ پرداخت واقعی، سرور، پنل مدیریت و تحویل خودکار سفارش هنوز پیاده‌سازی نشده.
- اگر خواستی نسخه ریلیز (امضاشده) بسازی، باید keystore اضافه کنی.
